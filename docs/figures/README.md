# Figures

Generated by `uv run pmm report` from the served bundle in the
[FigureKit](https://github.com/BenBotsch/FigureKit) style; do not edit by hand. Every figure exists
for a light and a dark page, with a transparent background, so one file fits every page colour of
its mode:

```text
<name>.svg        light page, for the web and the README
<name>-dark.svg   dark page
<name>.png        light page, 250 dpi (about 1600 px wide), for slides and tools without SVG
<name>-dark.png   dark page
card.png          1200 x 630 social preview (Open Graph, LinkedIn), opaque
card-dark.png     the same on a dark background
```

Text is stored as paths in the SVGs, so a page needs none of the fonts. CI runs
`uv run figkit check docs/figures`, which fails on a missing light/dark pair, an opaque chart or a
file above its size budget.

## Embedding

A README on GitHub picks the file from the reader's colour scheme:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/figures/pr-curves-dark.svg">
  <img src="docs/figures/pr-curves.svg" alt="Precision-recall curves of four candidates; gradient boosting with physical features is highest.">
</picture>
```

A website takes the SVGs the same way; the browser reads their size from the file. Social
preview, in the page `<head>`:

```html
<meta property="og:image" content="https://example.com/img/card.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Predictive maintenance MLOps: test PR-AUC 0.88, 37 of 51 failures found with 2 false alarms.">
```
